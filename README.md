# 瑞森集团 AI 提效与数字化底座知识站

这是基于首次管理层访谈、制造业流程学习、图纸/报价案例、用友ERP数据判断、AI Workflow与资本化准备逻辑整理出的静态知识站。

## 网站内容

- 管理层结论：降本提效 → 数据沉淀 → 数字化经营 → 资本化准备
- 当前诊断：约70人电子团队、私人微信、个人电脑/Excel、用友ERP
- 制造知识地图：RFQ、DFM、BOM、Routing、Setup/Run Time、NPI、ECR/ECN、MRP、PMC、WIP、OEE、IQC/IPQC/FQC/OQC、FAI、8D
- 图纸教学案例：2D / 3D / Assembly+BOM，以及5G通信钣金机箱示意RFQ
- 一期MVP：AI看图提参数 + 报价辅助 + 人工审核
- 数据底座：用友已有 / 需核查 / 未来补齐（CRM/PLM/MES/QMS）
- Digital Thread：RFQ → 图纸 → 报价 → PO → BOM/工艺 → 生产 → 质量 → 成本 → 回款
- 资本化准备：收入、成本/库存、研发/质量证据链
- 路线：2026–2027 AI提效 → 2028+ 数字化经营 → 2030–2035 长期资本化基础
- 2–4周首个Workflow验证计划

## 部署

使用 GitHub Pages + GitHub Actions。主分支每次更新后，`.github/workflows/pages.yml` 会自动发布静态站点。

> 如仓库尚未启用 GitHub Pages，需要在 Repository Settings → Pages → Build and deployment → Source 选择 **GitHub Actions**。
