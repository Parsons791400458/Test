核心诊断

图纸只是入口，真正的问题是企业没有形成“企业记忆”

瑞森每天都在产生制造经验，但信息分散在微信、文件、Excel和工程师脑中，无法持续复用、校准和学习。

信息分散

同一业务过程存在多个个人入口，难以形成唯一事实源。

经验依赖个人

看图、工艺、报价等核心判断高度依赖资深人员。

工时缺统一标准

当前人工报工主观性较强，会影响成本、人效和产能判断。

数据没有闭环

图纸、报价、实际工时、实际成本、质量结果之间没有持续反馈。

RFQRequest for Quotation，客户询价包。
DFMDesign for Manufacturability，可制造性评审。
BOM“食材清单”：做这个产品要用什么、多少。
Routing“菜谱”：先做什么、后做什么、走哪些工序。
Setup Time调机、装夹、编程、换刀等开工准备时间。
Run Time真正加工每一件产品所需时间。
NPI新产品导入：样件 → FAI → 小批 → 量产。
ECR / ECN工程变更申请 / 工程变更通知与版本管理。
MRP根据订单、BOM和库存计算需要买什么、何时买。
PMC生产与物料控制：订单、机器、人、材料如何排。
WIP在制品：已经投产但还没有做完的产品。
OEE设备综合效率，用于判断设备真实产出效率。
IQC / IPQC来料检验 / 制程质量检验。
FQC / OQC成品检验 / 出货质量检验。
FAIFirst Article Inspection，首件确认。
8D客诉后的根因、措施、验证与标准化闭环。
图纸案例

AI看图到底要“看”什么

图纸识别不是OCR结束。AI需要把文件转成制造可用的参数、工艺和成本输入。下方案例为教学示意，非瑞森真实客户图纸。

示例RFQ字段示例值
产品5G通信钣金机箱
数量1,000 pcs
输入文件STEP + 2D PDF + BOM Excel
材料AL5052，2.0 mm
表面处理Black Powder Coating
关键公差±0.10 mm
交期30 days

第一道AI Gate：先检查RFQ完整性、版本一致性、材料、数量、表面处理、公差、特殊质量和包装要求，再进入报价。

2D图纸

重点提取尺寸、公差、材料、表面处理、关键特性、Revision、特殊工艺说明。

3D STEP

重点解析几何、体积、孔槽、折弯、加工特征和潜在制造难点；不能只用OCR。

Assembly + BOM

重点理解装配关系、零部件数量、Make/Buy属性与最终产品结构。

一期MVP

AI看图 + 报价助手

第一阶段不追求“AI自动拍板报价”，而是让AI完成重复读取、整理、检索和计算，由工程 / 报价人员最终审核。

正式报价给客户
材料+加工工时+外协+模具/治具+损耗+包装物流+制造费用= 成本+定价策略 / 利润= 报价
关键学习点：历史“报价”不等于真实“成本”。如果报价100、成交90、实际成本75，成本模型应该尽量学习75；定价模型再考虑客户、数量、竞争与目标毛利。
数据底座

用友先做“账和交易事实”，新系统补过程数据

“用友具备某功能”不代表瑞森已经启用。第一步应该盘点版本、模块、字段和真实数据质量，再决定是否增加PLM、MES、CRM等系统。

收入证据链

RFQ → 报价 → PO → 生产 → 出库 → 签收 → 发票 → 回款

回答收入真实性、截止性、客户与订单对应关系。

成本 / 库存证据链

BOM → 领料 → Routing → 工时 → 外协 → WIP → 成品 → 出库

回答毛利是否可信、存货在哪里、在制品如何形成。

研发 / 质量证据链

立项 → 人员/工时 → 测试 → 版本/IP → 客户验证 → 订单 / 8D

回答研发投入、成果归属、质量改善和商业化闭环。
